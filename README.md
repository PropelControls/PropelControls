# Propel Controls Website

A complete static website for Propel Controls.

## Included

- Home page
- Solutions page with six solution cards
- Industries page
- About page
- Contact page
- Responsive CSS
- Mobile navigation
- SVG logo and favicon
- Abstract automation network visual
- Contact form that opens an email draft

## Before publishing

1. Change `hello@propelcontrols.com.au` in `script.js` to your real email address.
2. Review all wording so it accurately reflects your current services and experience.
3. Add genuine project photos/case studies only when available.
4. Upload the contents of this folder to a GitHub repository.
5. Enable GitHub Pages from the repository settings.
